# 🌱 MotorBalear S.L. · Plan de Sostenibilidad

Proyecto educativo desarrollado para el módulo **Sostenibilidad Aplicada al Sistema Productivo (SASP)** en los ciclos formativos de:

- CFGM Electromecánica de Vehículos Automóviles
- CFGM Carrocería

---

## 🚗 El proyecto

En lugar de trabajar mediante actividades aisladas, todo el módulo se estructura alrededor de una empresa ficticia:

**MotorBalear S.L.**

A lo largo de las diferentes unidades, el alumnado asume el papel de consultor de sostenibilidad y debe ayudar a la empresa a:

- Identificar problemas ambientales.
- Analizar retos sociales y empresariales.
- Priorizar actuaciones.
- Diseñar medidas de mejora.
- Elaborar un Plan de Sostenibilidad profesional.

Cada unidad aporta una pieza distinta al resultado final.

---

## 🎯 Objetivo didáctico

El objetivo es que el alumnado comprenda que la sostenibilidad no es únicamente un concepto teórico, sino una competencia profesional que afecta a:

- La gestión de residuos.
- El consumo energético.
- La economía circular.
- La movilidad eléctrica.
- La seguridad laboral.
- La relación con clientes y proveedores.
- La viabilidad futura del negocio.
